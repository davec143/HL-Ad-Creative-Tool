How to use this

  1. Pick the product. Search the catalog by name or SKU and click the result. The tool uses that product's own photograph from Shopify, so the hardware in the finished ad is the real thing. If a product has several photos, choose the one to build from. Not in Shopify? Switch to the URL tab and paste a direct image link.

  2. Check the stock chip. A red chip means zero units on hand — build the creative if you like, but don't put budget behind it until it restocks.

  3. Choose the template first. It sets which fields apply and their length limits. T1 Collage Hero: always-on brand for pros and installers. T2 Speech-Bubble Hero: B2B and contractor prospecting. T3 Discount Deadline: sales and deadlines — you write the offer and the deadline yourself. T4 Styled Room Hero: lifestyle for homeowners, no job-site imagery. T5 Glow Room Hero: the “Built For Professionals” look.

  4. Write the message, or have it drafted. Type the angle and press Write it for me — it reads the product listing and fills everything in for you to edit. Proof points must carry real figures from the product sheet; if a number isn't documented, leave it out.

  5. Describe the shot. One concrete sentence: who is in frame, what they're doing, where. The product carries over from the image you picked.

  6. Generate. The square renders first, then portrait and landscape are built from it. A set costs 6 Higgsfield credits. You can close the tab — the set keeps going and shows up under Recent sets.

  7. Read the checks on each file. Each file shows where the logo landed and a Text & logo check. A red note means don't use that file yet — press Regenerate this size (2 credits, rebuilt from the same square) or Regenerate the whole set on the square.

  8. Take the finished files. Download each size or the whole set as a zip. With Drive on, clean files are also filed in a folder named date + product. The raw render links are the generator's own output before cropping and the logo — never upload those to Ads Manager.

The brand system is already applied. Colours, Montserrat, the gold CTA, the layout order and the photography rules are built into what this tool sends. The logo is never drawn by the generator: the real HitLights file is placed on each finished image at a fixed position per template and size.

Reels aren't built here. The video ad is a separate deliverable — 1080×1920, 5–10 seconds, CTA or contact at the end.

Before you hand it over

  • Every check green. Text & logo check passed on all three, no red notes. Recent sets keeps the record.

  • Three files, one image. Look at the side-by-side strip — the same photograph, wording and colours in each.

  • Proof points specific. Every figure traced to the product sheet, never estimated to fill a line.

  • Landing page in stock. Check the SKU in Shopify first.
